Apache HTTP Server

Welcome to your Apache learning environment!

Quick Reference

Key Directives

  • ServerRoot - Base path for config/logs
  • Listen - Port to listen on
  • DocumentRoot - Document directory
  • DirectoryIndex - Default files (index.html)
  • ErrorLog - Error log location

Common Modules

  • mod_rewrite - URL rewriting
  • mod_ssl - SSL/TLS
  • mod_proxy - Proxy support
  • mod_auth_basic - Basic auth

Virtual Hosts

<VirtualHost *:80>
    ServerName example.com
    DocumentRoot "/var/www/html"
</VirtualHost>
Edit configs in conf/ directory to learn!
